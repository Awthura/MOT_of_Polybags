How to read it

Undistortion uses each camera's saved K/D with getOptimalNewCameraMatrix(alpha=1), so the corrected image keeps every source pixel — the bowed frame edge is the correction, not a crop.

Resolution

Both Baslers were recalibrated to 1280×720, the rig's operational resolution. Those streams are crops of the sensor (the aspect changed), so intrinsics were solved at that resolution — never rescaled from the old higher-res fits.

Two flags

lucid is a centre-anchored salvage — usable for coarse work, not metric. rgbd_1_color's distortion model is unreliable; adopt the RealSense factory intrinsics instead.
